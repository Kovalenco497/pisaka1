## 🔧 Технические детали

### База данных (Dexie/IndexedDB)
- channels - Telegram каналы
- channelProfiles - профили каналов
- contentMixes - настройки Content Mix
- schedules - расписания публикаций
- sources - источники контента
- sourceItems - элементы источников
- prompts - промпты для генерации
- aiProviders - AI провайдеры
- imageProviders - Image провайдеры
- posts - посты
- postVersions - версии постов
- jobs - задачи
- activityLogs - логи активности
- errorLogs - логи ошибок
- appSettings - настройки приложения

### Сервисы

#### crypto.ts
- `encryptKey()` - шифрование API ключей
- `decryptKey()` - расшифровка API ключей
- `maskKey()` - маскирование ключей для отображения

#### activity.ts
- `logActivity()` - логирование действий
- `getRecentActivity()` - получение последних логов
- `clearOldActivityLogs()` - очистка старых логов

#### research.ts
- `detectCategory()` - определение категории поста по теме

#### templateRenderer.ts
- `renderTemplate()` - рендеринг шаблонов промптов
- `buildPostContext()` - построение контекста для поста

#### telegram.ts
- `testTelegramConnection()` - тест подключения к Telegram
- `sendMessage()` - отправка текстового сообщения
- `sendPhoto()` - отправка фото с подписью
- `publishPost()` - публикация поста в Telegram

#### perplexity.ts
- `generateContentWithAI()` - генерация текста через Perplexity AI
- `generatePostWithPipeline()` - генерация поста с полным pipeline

#### image.ts
- `generateImageFromPost()` - генерация изображения из поста
- `buildImagePrompt()` - построение промпта для изображения

## 📝 Использование приложения

### 1. Создание канала
1. Перейдите в "Каналы"
2. Нажмите "Добавить канал"
3. Заполните название, username
4. Укажите Channel ID и Bot Token
5. Нажмите "Проверить подключение"
6. Сохраните

### 2. Настройка профиля канала
1. Нажмите "Профиль" на канале
2. Заполните бренд, описание, аудиторию
3. Укажите tone of voice, CTA, хештеги
4. Сохраните

### 3. Добавление источников
1. Перейдите в "Источники"
2. Нажмите "Добавить источник"
3. Укажите название, тип, URL, категорию
4. Сохраните

### 4. Создание поста
1. Перейдите в "Создать пост"
2. Выберите канал
3. Выберите категорию (auto, sales, trust, local, interactive)
4. Введите тему поста
5. Нажмите "Сгенерировать текст"
6. Нажмите "Сгенерировать изображение"
7. Просмотрите Preview
8. Сохраните черновик или опубликуйте

### 5. Автопилот
1. Перейдите в "Автопилот"
2. Выберите канал
3. Добавьте расписание
4. Укажите день, время, категорию

## 🎯 Особенности

### Генерация текста
- Использует Perplexity AI API
- Учитывает профиль канала
- Учитывает категорию поста
- Учитывает tone of voice

### Генерация изображений
- Использует OpenAI DALL-E API
- Анализирует содержание поста
- Определяет упомянутые автомобили
- Генерирует релевантные изображения

### Публикация в Telegram
- Автоматическая обрезка текста (4096 символов)
- Автоматическая обрезка подписи (1024 символа)
- Поддержка отправки фото с подписью
- Fallback на текст если фото не удалось отправить
